

## Compilar y ejecutar
Este proyecto está escrito en el lenguaje Rust y es necesario que primero tengas instalado el compilador de Rust. Compila el código fuente con el siguiente comando:

```
cargo build --release
```

Para ejecutarlo, copia el archivo `.env.example`, crea el archivo `.env` y configura las variables. Luego, ejecuta el binario compilado y disfrútalo. Asegúrate de que el archivo `.env` y el archivo binario se encuentren en el mismo directorio.
